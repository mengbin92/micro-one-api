# Micro-One API v0.45.5 发布公告

> 2026-11-18 · 上一版 [v0.45.4](./release-v0.45.4.md) · [GitHub Release](https://github.com/mengbin92/micro-one-api/releases/tag/v0.45.5)

v0.45.5 是 **PATCH 修复版本**，使管理台的用户分组操作符合现有 IAM 版本校验契约。

## 1. 分组授权提交用户和策略版本

**根因**。用户分组管理提交了路由访问版本，遗漏目标用户版本和授权策略版本。Identity 因此拒绝写入。

**修复**。页面从目标用户的分组访问回读取齐三个版本。用户和策略版本原样传递字符串，路由访问版本沿用数字。授予、撤销、修改默认分组和公开组访问共用此请求。

**影响服务**。管理台 Web 静态产物。

## 兼容性说明

服务端 API、数据库和权限判定沿用现有契约。旧授权模式仍可使用不带 IAM 版本的回读。

## 升级步骤

1. 构建 Web 静态产物，备份当前线上入口。
2. 上传新哈希资源，原子切换入口。
3. 用已有管理会话操作目标分组，核对用户授权读取结果和 IAM 审计。

回滚时恢复旧入口并保留其所引用的静态资源。
