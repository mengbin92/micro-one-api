# Micro-One-API v0.34.3 发布：IAM 权限详情可见性修复

> 2026-10-06 · 上一版：[v0.34.2](./release-v0.34.2.md)（2026-10-06）· [GitHub Release](https://github.com/mengbin92/micro-one-api/releases/tag/v0.34.3)

v0.34.3 是 v0.34.2 之后的 **PATCH 前端修复版本**：修复 `/admin/iam/permissions` 点击“详情”后缺少可见反馈的问题，保留原有独立权限、目录资料编辑和服务端预检提交流程。

**只更新前端 `web/dist`**。无 API/proto、数据库迁移、后端运行时或部署配置变更。

## 修复内容

### 1. 权限目录详情隐藏在长列表下方

**根因**：按钮只切换选中的记录，详情编辑器却固定渲染在整页表格之后。50 条权限的列表使编辑器落在当前视口之外，点击时既没有弹窗，也没有位置切换，用户看到的页面几乎不变。

**修复**：权限详情使用已有的响应式弹窗组件，在当前视口内展示记录和获准的引用关系；可关闭并重新选择其他条目。目录草稿创建也使用明确入口和相同弹窗。查看不要求元数据修改权限，修改按钮继续按精确权限显示，提交继续转入原有变更原因/预检/CAS 流程。

**影响范围**：前端 IAM 权限目录页面；其他 IAM 工作区及后端 owner 权限规则沿用原行为。

## 兼容性说明

- 只改变权限目录的详情/草稿展示位置，既有资料字段、请求载荷、权限门禁和服务端预检不变。
- 只读用户能查看已经获准列出的记录，不出现保存按钮；此次验收没有提交权限修改。
- 后端服务、IAM 模式和权限分配保持原样。保留 v0.34.1 的用量/用户字段/价格修复，以及 v0.34.2 的本人订阅会话转发修复。

## 升级步骤

1. 备份当前 `/opt/web/dist`。
2. 本机执行 `cd web && npm run build`，上传构建产物并核对摘要。
3. 发布新静态资源，保留旧 hash 文件，最后原子替换 `index.html`。前端挂载由宿主机提供，不需要重启容器。
4. 刷新权限目录页面，验证“详情”弹窗、关闭/切换记录、只读权限和原有编辑预检。
