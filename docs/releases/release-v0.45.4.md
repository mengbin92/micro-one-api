# Micro-One API v0.45.4 发布公告

> 2026-11-18 · 上一版 [v0.45.3](./release-v0.45.3.md) · [GitHub Release](https://github.com/mengbin92/micro-one-api/releases/tag/v0.45.4)

v0.45.4 是 **PATCH 修复版本**，补齐指定渠道代理入口的访问控制。

## 1. 指定渠道代理先校验模型和路由权限

**根因**。旧入口在鉴权后直接读取指定渠道，未核对 API Key 的模型权限和已授权路由组中的渠道映射。

**修复**。先核对模型白名单，再通过渠道服务校验当前路由组对该模型及指定渠道的有效授权。校验完成后才读取渠道凭据和预留额度。结算沿用同一已解析的路由上下文。入口仅转发可按模型授权的 POST 推理请求，沿用现有请求头白名单传递协议版本和功能选项。

**影响服务**。Relay Gateway。

## 兼容性说明

- 指定渠道推理需要明确提供 JSON `model`。该入口拒绝其他方法、查询参数和未列入允许范围的路径。客户端可通过 `/v1/models` 查看已授权模型，使用标准接口访问其他已支持的功能。
- 沿用现有服务间 API 和数据库结构。

## 升级步骤

1. 保留生产 Relay Gateway 的回滚镜像。
2. 部署本版 Relay Gateway，检查健康端点。
3. 核对授权请求可转发，以及拒绝请求未预留额度或触达上游。

如果回滚，先停用依赖本版隔离的新增渠道，再恢复上一镜像。
