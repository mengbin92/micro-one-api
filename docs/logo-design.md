# Micro-One-API Logo Design

## 设计目标

`micro-one-api` 的核心定位是 AI API 网关与管理系统：统一入口、多渠道路由、钱包账务、日志监控和后台运营。Logo 采用高识别度的单一网关符号，能稳定用于 favicon、后台侧栏、README 和发布物料。

## 图形语义

- 中央白色网关内嵌明确的数字 `1`，同时表达产品名中的 "One" 与统一入口，避免在小尺寸下被误读为数字 `0`。
- 左侧两条蓝色连线代表多客户端请求汇入，右侧两条分流线代表请求被路由到多个模型供应商和服务模块。
- 四个节点代表身份、渠道、账务、监控等微服务边界。
- 橙色节点代表钱包、扣费和账本能力，是项目区别于普通代理网关的重要特征。

## 色彩

- 深海军蓝背景（`#071A2B` → `#103D61`）：稳定、基础设施、生产可用。
- 系统蓝（`#4AA3FF`）：客户端和开发者 API，并与 Web 主交互色呼应。
- 薄荷绿（`#63D9C5`）：健康路由和供应商适配。
- 琥珀色（`#F5AD42`）：账务、余额和运营控制。
- 主字色（`#102334`）与强调蓝（`#0066CC`）：保证横向标识克制、清晰，并支持深色模式自动切换。

## 造型原则

- 强轮廓：圆角方形底板与中央 `1` 在 16px favicon 下仍可识别。
- 少装饰：仅保留一层低对比边界，不使用投影、玻璃高光或复杂纹理。
- 业务优先：所有节点和连线都有产品语义，不加入与 AI 网关无关的星芒、机器人或字母拼贴。
- 适配性：图标采用纯 SVG；横向标识使用同源 Noto Sans SC 字体，并为深色模式提供配色。

## 字标

- 正式名称显示为 `Micro-One API`，保留 `Micro-One` 的产品辨识度，减少连续连字符带来的视觉噪声。
- `API` 使用系统蓝强调，快速传达产品类别。
- 副标语为 `Unified AI gateway infrastructure`，概括统一入口、多渠道路由和平台化治理能力。
