## 3. 发布门禁

### 3.1 运营主体信息

发布候选验收先使用下列明显的测试占位值：

| 系统选项 | 测试值 |
|----------|--------|
| `LegalOperatorName` | `示例科技有限公司` |
| `LegalOperatorAddress` | `上海市示例路 1 号` |
| `LegalContactEmail` | `privacy@example.com` |

这些值只能用于本地、测试或明确的非生产验收；不写入运行时默认值，也不作为真实
法律主体发布。三项保存于现有系统选项，并由公开 `/api/status` 返回给法律页面。
在生产环境对外开放注册前，仍必须替换为真实运营者名称、注册地址和专用联系邮箱。

### 3.2 法律文本确认

当前协议明确适用中国大陆并以中文展示。发布前由运营者或其法律顾问确认主体、
计费 / 退款、生成内容标识、日志留存、未成年人和争议解决条款。机器翻译不用于改写法律正文。
