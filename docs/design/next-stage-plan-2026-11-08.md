## 2. 推荐顺序、交付与投入

按 1 名主工程师 + AI 辅助估算：**7–10 个工程日，另留 2 日共享余量，共 9–12 个工程日**。确认后起算；停写窗口、真实登录/商户/来源及观察等待单列，不据日期自动勾选完成。AI 并行准备代码核对、夹具和评审；生产变更串行进行。

| ID / 优先级 | 范围与 owner | 交付和退出条件 | 估算 / 依赖 |
| --- | --- | --- | --- |
| N1 / P1 | 计价与模型配置核验；Admin / Channel / Billing / Web | 逐模型只读核账表；区分疑似孤儿键、按量缺价、订阅专属及停用但合法配置；补价格发布的真实三库回归；需调整项形成具体差异，再经 owner + revision + 审计执行 | 2–3 日；先做无付费依赖的部分，改价与付费探测另确认 |
| N2 / P1 | 首次生产备份与隔离恢复；Backup / 运维 | 窗口和容量确认后完成首个全量备份；真实归档在独立空环境恢复并核对业务；测停写时长、容量及 RPO/RTO；异机副本可读回后再决定定时启用，观察至少两个调度周期 | 3–4 日；需停写窗口、独立恢复资源、异机存储目标；调度观察另计 |

**执行起点**：N1 先只读复核当前线上状态，同时准备 N2 的恢复资源和窗口；随后 N2 → N3 → N4。等待外部条件时可推进下一项不依赖该条件的验证，原项仍保留未完成。

### N1：复用现有价格链路

- 核对目录、别名/映射、路由与订阅来源、`ModelPrice`、`UpstreamModelPrice`、`ServiceTierPricing` 及请求/账本证据。复用未定价查询、规范模型 preflight、指标和价格管理入口，不新增治理平台。
- 对 [11 月 5 日价格清理遗留项](../runbooks/orphan-model-price-cleanup-2026-11-05.md)逐项确认。未证明无调用入口前不删价；订阅专属模型不按缺少按量价直接判错。模型删除与价格 owner 分离先记录，自动联动删除不纳入本轮。
- [v0.39.2 验证](../releases/release-v0.39.2.md)曾因本地 DSN 缺失跳过 MySQL/PostgreSQL。复用 `app/admin/internal/data/model_pricing_test.go`、`pricing_batch_test.go` 与 `platform/database/testutil` 的隔离三库边界，验证正式发布、并发合并、revision 冲突和审计回滚；缺断言时只补对应回归。缺真实结果不能记三库通过。
- A3/B1 已启用不等于真实收费验收通过。[日历已补齐并延至 2027-12-31](../runbooks/b1-holiday-calendar-2026-11-05.md)，不重复排期；调休周末按基础价是已登记边界，仅契约明确要求时另立变更。长上下文阈值仍未配置，不自动开启。
- 真实收费验收先固定来源、模型、各桶售价/采购估价、次数和预算；HTTP JSON/SSE 的 usage、快照、账本及可获得的上游供应商账单分别核对。缺实扣证据保留待验证，不以估价相符替代财务核验，不重算历史账本。

### N2：复用现有备份和恢复流程

- 沿用 `domain/backup`、`cmd/backup-worker`、[B3 契约](b3-managed-backup-contract-2026-10-30.md)与[恢复手册](../runbooks/b3-managed-backup-acceptance-2026-10-30.md)，不重建控制面或扩展数据库支持。
- 执行前列全 writer、配置/版本、密钥引用，确认离线解密身份、磁盘余量及可接受停写时间。备份后确认 writer 恢复、业务健康和未完成任务状态，不只检查归档存在。
- 使用生产归档和独立空卷，核对钱包、Token、渠道凭证解密、MFA、正金额待结算预扣幂等。记录归档哈希、数据时间点、恢复耗时、空间峰值及业务核对结果；RPO 24h/RTO 60min 目前仅为工程默认目标，需确认后用实测验收。
- 异机存储有两条可行路：“worker 直连现成异机私有对象存储”少一条复制链路，但依赖远端连接/权限；“保留同机存储并异机复制加密制品及恢复索引”保留本地路径，但需验证复制完整性和保留策略。目标未确定前不预选服务或采购资源。
- 异机副本未就绪时，首个备份和隔离恢复可独立验收，灾难恢复仍未完成。生产覆盖恢复不在本计划内。

## 5. 实施与发布边界

- 实施在 develop 或隔离 worktree 中转，提交归 develop。发现问题时先按项目 diagnosing-bugs 建立反馈环；核验线索不记为已定位 bug。
- 按工作包执行计划内验证，包括 N1 既有价格链路的真实三库补验；修改代码再补受影响层测试、race、协议及桌面/移动验收。候选按 PJR、自审及非平凡提交前 `ocr review` 门禁办理。本次仅规划文档，未构建或运行业务测试。
- 核验、配置治理和文档不预设新版本。修复既有行为倾向 PATCH，新增公开能力或计价契约判 MINOR；发布前按最终 diff 显式说明理由，补齐 release note / CHANGELOG / README 和 develop → main → tag。
- 生产停写、调价、付费请求、强制认证开关及用户公告，在具体内容、窗口、预算/受众可审阅后确认；本规划不代表这些动作已获授权。部署沿用本机交叉构建、回滚锚点和现场验证。
- 分别登记工程验证、生产部署、真实验收和外部条件；缺证据保留未完成，不因窗口耗尽宣布完成，不新建自动任务。
