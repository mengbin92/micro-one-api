## 1. 交付范围

本阶段按试用反馈补齐日常操作的解释链路，不改变分组准入、预扣和结算语义：

- **新组启用条件**：分组详情展示接线检查——资源成员、价格解析、启用时的能力版本与价格闸门、启用后的授权要求。价格不可用时明确提示启用会被后端拒绝；资源为空只提示操作风险，不替代后端闸门。
- **目标用户可用目录**：新增管理员接口 `GET /api/v1/admin/routing-access/{user}/available`。接口复用既有 `AvailableGroups` 用例与分页 / 过滤 / 排序校验，目标用户只来自路径，不信任请求体；返回该用户当前有效访问来源、模型、有效倍率、价格来源 / 版本、结算模式和订阅覆盖状态。
- **授权来源与有效价格**：管理员用户授权弹窗按目标用户展示“当前可用分组与有效价格”，把 `admin / migration / subscription / public` 来源转成可读解释，并说明用户专属倍率是替换而非相乘、报价是读取时结果。用户 Token 页面同步展示有效倍率、用户专属标识、实际结算模式和价格来源。
- **覆盖解释**：资源优先级 / 权重覆盖说明明确“覆盖仅作用于该分组、空值继承、不影响同一资源在其他分组的表现”。
- **扣费解释**：调用日志详情解析 v2 冻结请求快照，展示选择方式（inherit / fixed / ordered 及候选序号）、结算策略版本、预扣时冻结的有效倍率、计价方式、订阅证据和实际订阅 / 钱包分账；无快照的历史账单明确不可反推当时授权或价格来源。原始冻结 JSON 仍保留用于取证。
