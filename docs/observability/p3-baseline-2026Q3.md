## 6. 季度结论

- 入口流量：峰值 0.2 RPS，平均 0.0215 RPS；首次快照无环比。
- P95 延迟：平均 3.23s，最大 bucket 值 10s；主要 path 为 `/v1/responses`。
- 429 / 502：429 为 0%；502 峰值 50% 来自极小样本单点，不满足“周均值持续 >1% 且伴随熔断/账号池饱和”的观察提示。
- Dedupe claim：27,400 行；claim/ledger 7 天新增均为 7,584，代理比值 1.00；双向覆盖 PASS。
- 熔断：观察到 3 个打开样本，1h step 不足以统计完整次数与最长持续时间。
- P3 建议：无。当前证据不足且不满足触发条件；继续保持观察，不启动 ADR。
